# gesture2sound

タッチ、ペン、マウスのジェスチャを音に変換するWebベースのシンセサイザー。

## コンセプト

このアプリケーションは、仮想の弦楽器のように動作します。画面をタッチすると**アンカーポイント**が作成されます。このアンカーから指やマウスをドラッグすると、「弦を引く」ように音が鳴ります。引く方向と距離、そしてタッチの圧力によって、音の高さ（ピッチ）、音量、音色が動的に変化します。

## 特徴

- **表現力豊かなコントロール:** 入力位置、距離、圧力を使って音を動的に変化させます。
- **マルチタッチ / ペン対応:** 複数の音を同時に鳴らし、和音（コード）や複雑なサウンドスケープを作り出すことができます。
- **直感的な視覚フィードバック:** 各入力はアンカーポイントと移動する「ヘッド」で表現され、ジェスチャがどのように音へマッピングされているかが視覚的にわかります。
- **リアルタイム音響合成:** Web Audio APIを活用し、純粋なサイン波から倍音豊かな音色まで、リアルタイムに波形を変化させます。

## 操作方法

1. **エンジンの起動:** **Audio ON** ボタンをクリックして、Web Audioコンテキストを有効にします（ブラウザの仕様上必要です）。
2. **音を鳴らす:** 指、マウス、またはペンで画面を押したままにします。これにより**アンカーポイント**が設定されます。
3. **音を変化させる:** アンカーポイントからドラッグして、音を鳴らしながら変化させます。

### コントロール

- **音の高さ（周波数）:** アンカーからの**水平距離（左右）**で制御します。右に動かすと高くなり、左に動かすと低くなります。音楽のオクターブに対応した対数スケールになっています。
- **音量（ゲイン）:** アンカーからの**垂直距離（上下）**で制御します。上に動かすと音が大きくなり、下に動かすと小さくなります。
- **音色（倍音）:** **圧力**で制御します。軽く押すと純粋なサイン波になり、強く押すと奇数倍音が加わって矩形波（スクエア波）に近い音色に変化します。
